STAR CITY — сайт жилого комплекса
=================================

Что внутри
----------
- Клиентский сайт: регистрация, вход, выбор услуги и отправка заявки.
- Кабинет работников: список заявок и кнопка «Принять заявку».
- После принятия заявки открывается чат клиента с назначенным сотрудником.
- В чате можно писать сообщения и прикреплять фотографии/референсы.
- Данные хранятся локально в SQLite (файл starcity.db создастся автоматически).

ЗАПУСК НА WINDOWS 10/11
-----------------------
1. Установите Python 3.11 или новее с https://www.python.org/downloads/
   Во время установки отметьте «Add Python to PATH».
2. Распакуйте ZIP в удобную папку, например C:\\StarCity.
3. Откройте эту папку в Проводнике.
4. В адресной строке папки напишите cmd и нажмите Enter.
5. В командной строке выполните:

   py -m venv .venv
   .venv\\Scripts\\activate
   py -m pip install -r requirements.txt
   py app.py

6. Откройте браузер и перейдите на:
   http://127.0.0.1:5000

КАК ПРОВЕРИТЬ РАБОТУ
--------------------
1. Откройте сайт и зарегистрируйте тестового клиента.
2. В кабинете клиента выберите «Квартира без ремонта» или «Квартира с ремонтом».
3. Заполните телефон и отправьте заявку.
4. Выйдите из аккаунта.
5. Войдите как работник по демо-данным выше.
6. Откройте заявку и нажмите «Принять заявку».
7. В чате отправьте сообщение и прикрепите фото.
8. Выйдите и войдите обратно клиентом — ответ сотрудника будет виден в том же чате.

ВАЖНО ПЕРЕД ПУБЛИКАЦИЕЙ В ИНТЕРНЕТЕ
-----------------------------------
Это рабочий демонстрационный прототип, а не готовая защищённая банковская/CRM-система.
Перед публичным запуском:
- замените SECRET_KEY на длинный случайный секрет через переменную окружения;
- смените пароль демо-сотрудника и создайте личные аккаунты сотрудникам;
- отключите debug=True;
- используйте HTTPS и production-сервер (например, Waitress или Gunicorn);
- добавьте защиту от CSRF, лимиты/проверку содержимого файлов, резервное копирование;
- настройте правила хранения персональных данных и согласие на их обработку;
- настройте домен и хостинг.

ГДЕ МЕНЯТЬ ДИЗАЙН И ЛОГОТИП
---------------------------
- Логотип: static/logo.png (можно заменить своим файлом с тем же именем).
- Цвета и оформление: static/style.css.
- Тексты и страницы: папка templates.
- Логика и база данных: app.py.

Сайт по умолчанию доступен только на этом компьютере (127.0.0.1).
Чтобы другие люди могли заходить на сайт из интернета, нужен отдельный хостинг и настройка домена.
